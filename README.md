## Как открыть

**Сайт** — конвертер и каталог форматов. Локально он открывается по адресу из **`APP_URL`** в `.env` (в примере — `http://convertal.docker.local`) или по `http://localhost`, порт **80**.

Имя **`convertal.docker.local`** нужно прописать в `/etc/hosts`:

```text
127.0.0.1 convertal.docker.local
```

**Главная** сразу открывает пару **PDF → DOC**. Тот же экран живёт и по адресу пары, например `/pdf-docx` или `/png-jpg`.

**Форматы** — список всех пар. Адрес: `/formats`.

Вход, пароль и личный кабинет не используются. Почта и перехват писем в проекте не настроены.

## Как устроен экран

Светлая страница на шрифте Manrope. Если в системе включена тёмная тема, страница тоже становится тёмной.

### Конвертер

| Часть экрана | Что здесь |
| --- | --- |
| **Шапка** | Логотип Convertal и два пункта: **Конвертер**, **Форматы**. Шапка остаётся наверху при прокрутке. |
| **Заголовок** | Название пары и короткая подпись. На главной это «Конвертер PDF в DOC». |
| **Область загрузки** | Кнопка **Выберите файлы**, подсказка про перетаскивание и лимит 100 МБ. После выбора файлов здесь появляется список. |
| **Пара форматов** | Две кнопки с названиями форматов и слово **В** между ними. |
| **Под формой** | Три карточки «зачем эта пара», три шага, описание обоих форматов, вопросы и ссылки на остальные пары. |
| **Подвал** | Короткое описание, ссылки на разделы, ограничения и подпись автора. |

На узком экране пункты шапки остаются на виду. Кнопки форматов и карточки встают друг под другом.

### Форматы

| Часть экрана | Что здесь |
| --- | --- |
| **Шапка и подвал** | Те же, что на конвертере. Пункт **Форматы** подсвечен. |
| **Основная область** | Две группы: **Документы** и **Изображения**. В каждой — карточки пар со ссылкой на конвертер. |

## Конвертер

### Шапка и подвал

| Элемент | Что произойдёт |
| --- | --- |
| Логотип | Открывает главную, пару **PDF → DOC**. |
| **Конвертер** | Тоже открывает главную. Пункт подсвечен на главной и на странице любой пары. |
| **Форматы** | Открывает `/formats`. |
| Ссылка в подвале | Ведёт на главную, на каталог, на **PDF в DOCX** или на **PNG в JPG**. |
| Имя автора и значок GitHub | Открывают профиль и репозиторий проекта в новой вкладке. |

### Выбор файлов

Пока файлов нет, видна кнопка **Выберите файлы** и текст «Перетащите файлы сюда. 100 МБ — максимальный размер файла.»

| Что сделали | Что произойдёт |
| --- | --- |
| Нажали **Выберите файлы** или **Добавить ещё файлы** | Откроется выбор файлов. Можно отметить несколько. |
| Перетащили файлы в белую область | Они попадут в тот же список. Рамка на время перетаскивания подсвечивается. |
| Расширение не подходит к выбранному формату | Строка красная: «Нужен файл PDF» (или DOC, DOCX, JPG, JPEG, PNG — по текущему формату). Кнопка **Конвертировать** такую строку не отправляет. |
| Файл пустой | «Файл пустой.» |
| Файл больше 100 МБ | «Файл больше 100 МБ.» |
| JavaScript выключен | Под кнопкой текст: «Загрузка файлов работает с включённым JavaScript.» Без скрипта файл не уходит. |

Для JPG и JPEG подходят оба расширения: `.jpg` и `.jpeg`. Для PDF, DOC, DOCX и PNG — только своё расширение.

Список показывает имя, размер, пару форматов и статус: **Ожидает**, **Конвертация…**, **Готово** или текст ошибки. **Удалить** убирает строку из списка на странице. Уже готовый файл на сервере от этого не стирается: он доживёт до своего двухчасового срока.

Если сменить пару форматов, строки в статусе **Ожидает** и строки с ошибкой проверяются заново. Уже готовые и те, что сейчас конвертируются, остаются как есть.

### Выбор форматов

Под областью загрузки две кнопки: исходный формат слева, конечный справа.

| Что нажали | Что произойдёт |
| --- | --- |
| Левая кнопка | Выпадает список **Исходный формат**. Повторное нажатие, щелчок мимо списка или клавиша **Esc** его закрывают. |
| Правая кнопка | Выпадает список **Конечный формат**. Закрывается так же. |
| Формат, который можно выбрать | Страница меняет заголовок, тексты, вопросы и адрес без перезагрузки. Кнопка **Назад** в браузере возвращает предыдущую пару. |
| Серая кнопка в списке | Формат для этой стороны недоступен, нажатие ничего не меняет. |

Слева доступны только форматы, из которых есть хотя бы одна пара: PDF, DOC, DOCX, JPG, JPEG, PNG. Справа — только то, во что выбранный формат умеет превращаться. Если новый исходный формат не умеет текущий конечный, конечный сам становится первым доступным. Например, с **PDF → DOCX** переход на **DOC** даёт **DOC → PDF**.

### Конвертация и скачивание

Кнопка **Конвертировать** появляется, когда в списке есть хотя бы один файл. Она неактивна, пока нет строк **Ожидает** или пока идёт отправка.

| Что произошло | Что увидит пользователь |
| --- | --- |
| Нажата **Конвертировать** | Строки **Ожидает** уходят по одной. У текущей статус **Конвертация…**. |
| Сервер принял файл | Статус **Готово**, имя меняется на имя результата, появляется кнопка **Скачать**. |
| Файл не подошёл или конвертация не удалась | Красный текст с причиной. Остальные файлы в очереди продолжают уходить. |
| С одного адреса больше 30 отправок за минуту | «Слишком много конвертаций. Подождите минуту и попробуйте снова.» |
| Сеть или сервер недоступны | «Не удалось связаться с сервером.» |

**Скачать** сохраняет файл по ссылке вида `/conversions/` и сорок символов. Ссылка действует два часа. Чужой или просроченный адрес открывает страницу **404**.

Сообщения, которые может вернуть сервер:

| Причина | Текст |
| --- | --- |
| Файл не пришёл | «Выберите файл.» или «Не удалось загрузить файл.» |
| Больше 100 МБ | «Файл больше 100 МБ.» |
| Расширение не совпало с форматом | «Расширение файла не совпадает с выбранным форматом.» |
| Внутри не тот тип | «Содержимое файла не похоже на PDF» — или на PNG, JPEG, DOC, DOCX, в зависимости от выбранного формата. |
| Такой пары нет | «Эта пара форматов не поддерживается.» |
| Документ повреждён или LibreOffice его не собрал | «Не удалось конвертировать документ. Проверьте, что файл не повреждён.» |
| На сервере нет LibreOffice | «Конвертация документов сейчас недоступна.» |
| Картинка не читается | «Файл не является изображением.» или «Не удалось прочитать изображение.» |
| Картинка больше 40 миллионов пикселей | «Изображение слишком большое.» |

### Блоки под формой

Тексты этих блоков меняются вместе с парой.

| Блок | Что внутри |
| --- | --- |
| **Три карточки** | Зачем нужна эта пара, что обработка идёт на сервере, что исходник удаляется сразу, а результат — в течение двух часов. |
| **Как сконвертировать** | Три шага: выбрать файлы, проверить формат, скачать результат. |
| **О форматах** | Две карточки: что это за формат, кто его сделал и в каком году. |
| **Частые вопросы** | Шесть раскрывающихся вопросов. Все свёрнуты, открывается тот, на который нажали. |
| **Связанные конвертации** | Ссылки на остальные пары. Текущей пары среди них нет. |

## Форматы

Страница `/formats` собирает пары из `config/conversions.php` в две группы.

**Документы** переводятся через LibreOffice:

| Пара | Зачем |
| --- | --- |
| **PDF → DOC** | DOC нужен, если документ должны открыть программы, которые не работают с PDF или с современным DOCX. |
| **PDF → DOCX** | Текст и абзацы из PDF переносятся в документ, который можно править. |
| **DOC → PDF** | Вид документа фиксируется и открывается без Word. |
| **DOCX → PDF** | Документ можно отправить так, чтобы оформление не разъехалось в другой версии Word. |

Сложная вёрстка PDF — колонки, колонтитулы, точное положение картинок — при переводе в DOC и DOCX может упроститься. При переводе DOC и DOCX в PDF редкий шрифт заменяется близким, если его нет на сервере.

**Изображения** переводятся средствами PHP, без LibreOffice:

| Пара | Что меняется |
| --- | --- |
| **JPG → PNG** и **JPEG → PNG** | Пиксели сохраняются. Прозрачности не появляется: у JPEG её нет. |
| **PNG → JPG** и **PNG → JPEG** | Картинка сжимается как JPEG. Прозрачные области становятся белыми. |

JPG и JPEG — один и тот же вид сжатия. Разница страниц в расширении готового файла: `.jpg` или `.jpeg`.

## Что происходит с файлом

1. Браузер проверяет расширение, пустоту и размер, затем отправляет файл вместе с выбранной парой.
2. Сервер ещё раз проверяет размер, пару и начало файла. Документ DOC, PDF и картинки узнаются по первым байтам, DOCX — по архиву, внутри которого есть `word/document.xml`.
3. Документ отдаётся LibreOffice. Картинка читается как JPEG или PNG. У JPEG учитывается поворот из данных снимка. PNG с прозрачностью при сохранении в JPEG ложится на белый фон.
4. Исходник удаляется сразу после успешной конвертации. Если конвертация сорвалась, временная папка удаляется целиком, скачивать нечего.
5. Готовый файл лежит в `storage/app/private/conversions/`. Ссылка на скачивание живёт в кэше два часа. Имя берётся из исходного: недопустимые символы заменяются, длинное имя обрезается, расширение становится целевым.
6. При следующей конвертации папки старше двух часов удаляются.

Ссылку на скачивание может открыть любой, у кого она есть, пока не истекли два часа. После этого и кэш, и файл перестают находиться.

## Запуск

Нужны Docker и файл `.env` в корне репозитория. Его собирают из `.env.example`.

В `/etc/hosts` добавляют строку `127.0.0.1 convertal.docker.local`, затем:

```bash
make up
make migrations-up
docker compose exec application npm install
docker compose exec application npm run build
```

`make up` поднимает контейнеры. `make migrations-up` создаёт таблицы сессий и кэша: без них страница не держит сессию, а ссылка на скачивание не сохраняется. Команды `npm` собирают стили и скрипт страницы.

Поднимаются два сервиса:

| Сервис | Зачем | Порт на компьютере |
| --- | --- | --- |
| **application** | Laravel на PHP 8.5. Корень репозитория смонтирован в контейнер. Для документов внутри должен находиться LibreOffice (`soffice`). | **80** |
| **database** | MariaDB. База, пользователь и пароль — из `.env`. | **3306** |

Остановить контейнеры, не трогая данные: `make stop`.  
`make down` удаляет контейнеры **и тома**, включая базу.

Пока контейнеры запущены:

```bash
make artisan CMD="route:list"
make cache-clear
make test
```

`make artisan` выполняет Artisan внутри контейнера приложения.

Код экранов лежит в `resources/views`, поведение формы — в `resources/js/converter.js`. Пары, тексты и лимит размера — в `config/conversions.php`. Загрузка и отдача файла — в `app/Http/Controllers`, проверка и сама конвертация — в `app/Actions` и `app/Support`.

### Переменные `.env`

| Переменная | Зачем |
| --- | --- |
| **`APP_HOST`** | Имя сайта для PHP, в примере `convertal.docker.local`. |
| **`APP_PATH`** | Куда внутри контейнера смонтирован репозиторий. |
| **`APP_NAME`** | Название приложения. |
| **`APP_URL`** | Адрес, по которому открывают сайт. |
| **`APP_KEY`** | Ключ сессий и cookie. Пустое значение заполняют командой `make key-generate`. |
| **`APP_LOCALE`** | Язык приложения, для этого проекта `ru`. |
| **`DB_CONNECTION`**, **`DB_HOST`**, **`DB_PORT`**, **`DB_DATABASE`**, **`DB_USERNAME`**, **`DB_PASSWORD`**, **`DB_ROOT_PASSWORD`** | Доступ к MariaDB. Хост внутри сети Docker — `database`, порт `3306`. |
| **`LARAVEL_CRON_ENABLED`** | **`1`** — планировщик Laravel запускается раз в минуту. **`0`** — не запускается. На конвертацию это не влияет: файлы старше двух часов удаляются при следующей загрузке. |
| **`LIBREOFFICE_BINARY`** | Имя или путь программы LibreOffice. Если переменной нет, ищется `soffice`, затем `libreoffice`. |

Пароли из `.env` в инструкцию сверх примера не копируйте: боевые значения хранятся только на сервере.

## Частые вопросы

**Где поменять заголовок, описание формата или ответ в вопросах?**  
В `config/conversions.php`: подписи и описания — в **`formats`**, «зачем эта пара» — в **`reasons`**, примечание про оформление — в **`layout_notes`**, «чем открыть» — в **`opens_with`**. После правки обновите страницу. Сборка фронтенда для этих текстов не нужна.

**Как добавить ещё одну пару?**  
В том же файле: конечный формат добавляется в **`pairs`**, а для новой пары — строки в **`reasons`** и **`layout_notes`**. Документы умеют PDF, DOC и DOCX. Картинки умеют JPG, JPEG и PNG. Пара вне этих наборов в коде конвертера не заработает одной правкой конфига.

**Почему кнопка «Конвертировать» серая?**  
В списке нет строк со статусом **Ожидает**. Файл уже готов, ещё конвертируется или отклонён проверкой. Исправьте файл либо добавьте другой.

**Почему файл есть в списке, но не уходит?**  
Строка красная. Чаще всего расширение не совпало с выбранным слева форматом, файл пустой или больше 100 МБ. Если браузер файл пропустил, а сервер нет, в строке будет текст сервера: неверное содержимое, слишком большая картинка или сбой конвертации.

**Куда делся готовый файл?**  
Он скачивается кнопкой **Скачать** в своей строке. Ссылка жива два часа. Потом адрес открывает **404**, а файл с диска удаляется при следующей конвертации.

**Почему у PNG пропала прозрачность?**  
Перевод в JPG и JPEG кладёт картинку на белый фон: у JPEG прозрачности нет. Чтобы фон сохранился, нужна пара в PNG.

**Почему PDF в Word выглядит проще, чем исходник?**  
LibreOffice переносит текст и абзацы. Колонки, колонтитулы и точное положение картинок могут упроститься. Это написано в вопросах на странице пары.

**Почему документы не конвертируются, а картинки конвертируются?**  
Картинки обрабатывает PHP. Документам нужен LibreOffice в контейнере приложения. Если программы нет, сайт отвечает: «Конвертация документов сейчас недоступна.» Путь можно задать переменной **`LIBREOFFICE_BINARY`**.

**Почему сайт просит подождать минуту?**  
С одного адреса принимается 30 конвертаций за минуту. Следующие получат «Слишком много конвертаций. Подождите минуту и попробуйте снова.»

**Чем JPG отличается от JPEG на сайте?**  
Это один формат с двумя расширениями. Страницы разные, чтобы скачанный файл получил `.jpg` или `.jpeg`. Загрузить можно файл с любым из этих расширений.

**Можно ли конвертировать несколько файлов сразу?**  
Да. Каждый уходит отдельно и скачивается своей кнопкой. Ошибка одного файла не останавливает остальные.

**Нужно ли собирать фронтенд после правки текстов в конфиге?**  
Нет. Сборка нужна, когда меняются `resources/js` или `resources/css`: `docker compose exec application npm run build`.
